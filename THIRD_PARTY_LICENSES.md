## FFmpeg

FFTool bundles FFmpeg components for media processing.

Bundled FFmpeg components:

- ffmpeg.exe
- ffprobe.exe
- avcodec-62.dll
- avdevice-62.dll
- avfilter-11.dll
- avformat-62.dll
- avutil-60.dll
- swresample-6.dll
- swscale-9.dll

- Build: ffmpeg-n8.1.2-34-g9b6c8969e0-win64-gpl-shared-8.1
- Architecture: Windows x64
- Configuration: GPL shared build
